# Uploading the checkpoint

Upload the CONTENTS of this English submission folder into the team repository;
do not upload the whole local project directory. Keep src/, notebooks/, configs/,
results/,evidence/ and the English Markdown/JSON files. The .gitignore excludes
datasets, model checkpoints, ZIPs and local runtime directories.

On GitHub, open the target repository, choose Add file -> Upload files, add the
files/folders and review the change before committing. Large raw data and .pt
files do not belong in this checkpoint upload. A private repository needs
appropriate instructor access, arranged by the repository owner.

Suggested commit message: Add C3 midway checkpoint and validation pilot results.
After upload, verify that README renders, results CSV is visible and the notebook
is present. Submit the repository link through the course's designated channel.
This preparation has not published or submitted anything.

GitHub reference: https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
